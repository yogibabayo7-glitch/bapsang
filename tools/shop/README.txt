오늘밥상물가 - 토스쇼핑 추천 상품 자동 갱신 (내 컴퓨터에서 하루 한 번)

하는 일
  매일 아침 토스쇼핑 김장·채소·과일 등 카테고리 인기 상품을 가져와서
  내 쉐어링크를 만들고, 오늘밥상물가 앱이 읽는 목록(shop.json)을 GitHub에 올려요.

준비 1. 이 폴더를 원하는 곳에 둬요 (예: 문서\밥상물가\shop). 나중에 옮기면 1_install.bat을 다시 실행해요.
  - 파일을 새 버전으로 바꿀 땐 폴더 안 파일을 전부 덮어써요. (shop-config.json·pins.json·link-cache.json은 그대로 둬요)
  - bapsang-shop.ps1 과 shop-lib.ps1 은 꼭 같이 있어야 해요.

준비 2. shop-config.json 만들기
  - shop-config.json.example 파일을 복사해서 이름을 shop-config.json 으로 바꿔요.
  - 메모장으로 열어서 채워요.
      accessKey   : 쉐어링크 → 연동 → API 키 발급 → Access Key (복사 버튼)
      secretKey   : 같은 화면의 Secret Key
      publisherId : 이미 채워져 있어요 (회원 연동 ID)
      githubToken : 아래 준비 3에서 만든 토큰
  - 이 파일에는 비밀 키가 들어 있으니 다른 사람에게 보내거나 채팅에 올리지 마세요.

준비 3. GitHub 토큰 만들기 (앱 데이터 저장소에 파일 하나 올리는 권한)
  1) github.com 로그인 → 오른쪽 위 프로필 → Settings
  2) 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3) Token name: bapsang-shop / Expiration: 1 year
  4) Repository access: Only select repositories → bapsang
  5) Permissions → Repository permissions → Contents: Read and write
  6) Generate token → 나온 값(github_pat_...)을 복사해서 githubToken에 붙여넣기

준비 4. 1_install.bat 더블클릭
  - 매일 오전 9시 40분 자동 실행으로 등록하고, 지금 한 번 바로 돌려봐요.
  - "이 컴퓨터의 인터넷 주소는 ○○○ 예요" 라고 나오면:
    쉐어링크 → 연동 → API 키 발급 → 출발지 IP → 수정 → 그 주소를 추가하고 저장한 뒤
    2_run_now.bat 을 더블클릭해서 다시 돌려요.
  - "완료! 상품 ○○개를 올렸어요" 가 나오면 끝이에요.

그 뒤
  - 컴퓨터가 꺼져 있던 날은 다음에 켤 때 자동으로 돌아요. 못 돌아도 앱에는 전날 상품이 그대로 나와요.
  - 집 인터넷 주소가 바뀌면 shop-log.txt 에 새 주소가 적혀요. 그 주소를 출발지 IP에 추가하면 돼요.
  - 특정 상품을 빼야 하면(판매자 요청 등) shop-config.json 의 "block" 에 상품 번호를 넣어요. 예: "block": ["12345"]
  - 기록은 shop-log.txt 에 남아요.

품목별 상품 (10/28 추가)
  - 앱 '전체 시세'에서 품목을 누르면 그 품목 상품만 나와요 (상추면 상추, 콩이면 콩, 쌀이면 쌀).
  - 품목마다 정해진 토스쇼핑 카테고리(예: 채소류 > 쌈채소 > 상추)의 인기 상품 중에서
    이름 규칙에 맞는 것만 골라요. 주스·가루·씨앗·다른 품목은 빠져요. 맞는 상품이 없는 날은 그 칸이 안 보여요.
  - 규칙은 GitHub의 docs/data/shop-rules.json 을 매일 내려받아 써요 (이 폴더에 shop-rules.json 으로 저장).
    규칙을 고쳐도 이 폴더 파일은 바꿀 필요 없어요.
  - 한 번 만든 상품 링크는 link-cache.json 에 저장해 두고 다시 써요. 지우면 다음 실행 때 새로 만들어요.
  - shop-log.txt 의 "품목별 상품: 108개 품목 중 ○개에 상품 있음" 줄로 확인해요.

하루 조회 한도 (10/28 밤 추가)
  - 토스 쉐어링크 API는 상품 목록·상세로 받아 가는 상품이 하루 1만 개까지예요 (밤 12시 초기화).
    예전엔 이 한도를 넘겨서 '다음 쪽' 조회가 다 막혔어요 → 카테고리마다 1쪽(100개)만 본 셈.
  - 이제 오늘 쓴 개수를 quota.txt 에 적고 9,300개에서 스스로 멈춰요.
  - 받은 인기 상품은 best-cache.txt 에 저장해요 (순위가 바뀌는 오전 9시까지). 같은 날 다시 돌려도 한도를 거의 안 써요.
  - 상품 없는 품목부터 깊게 찾아요: 같은 카테고리 끝까지 → 한 단계 위 → 두 단계 위.
    깊게 찾아서 나온 상품은 found.txt 에 기억해 두고 다음 날엔 상세 조회로만 확인해요(한도를 거의 안 씀, 14일 보관).
  - shop-log.txt 의 "인기 상품 조회: … 모두 ○쪽 … 오늘 조회 사용 ○/10,000개" 줄로 확인해요.
  - 한도에 막혀 상품이 크게 모자란 날은 올리지 않아요 (앱엔 어제 상품이 그대로 나와요).

상품 찾기 · 고정하기 (3_search.bat, 10/28 밤 추가)
  - 토스 API엔 '검색어로 찾기'가 없어서, 카테고리 인기 상품을 받아 이름으로 걸러 찾아요.
  - 3_search.bat 더블클릭 → 찾을 말 입력 (예: 열무 / 한우 안심 / 꽁치)
      1) 오늘 받아 둔 상품에서 먼저 찾아요 (한도 안 씀)
      2) 더 찾고 싶으면 보여 주는 카테고리 번호를 골라요 (1쪽 = 100개만큼 한도를 써요)
      3) 결과가 번호 목록 + 사진 화면(search-result.html)으로 나와요. ✓ 표시는 품목 이름 규칙 통과.
      4) 고정할 품목 이름(그냥 엔터 = 찾은 품목) → 고정할 번호 입력 (예: 1,4)
         빼기: x1 / 상품번호 직접 넣기: #2398866849
  - 고정한 상품은 pins.json 에 저장되고, 매일 아침 그 품목 맨 앞에 나와요. 이름 규칙은 안 봐요(사람이 고른 거라).
    품절·판매 끝난 날은 그날만 빠지고, 판매 끝은 shop-log.txt 에 번호가 적혀요 → 3_search.bat 에서 x번호로 빼요.
  - 다 하고 마지막에 y 를 누르면 바로 앱 상품을 새로 올려요.
