# 오늘밥상물가 v0.4 출시 키트 (요이땅 문서)

## 출발 조건 (셋 다 되면 출발)
- [ ] 배너 광고 그룹 승인 → 광고 그룹 ID 받기 (콘솔 인앱 광고 > 광고 그룹 탭)
- [ ] 콘솔 사업자/정산 정보 승인 (내 정보 > 정산 정보 '검토 중' → 승인). 승인 후 담당자명·이메일·정산 계좌 비어 있으면 채우기
- [ ] v0.3 출시 완료 (검토 중일 때 새 버전 올리면 v0.3 검토가 꼬일 수 있음)

## 요이땅 순서
1. 사장님: 배너 ID를 Claude에게 전달
2. Claude: `bash scripts/release.sh <배너ID> '' ''` → `release/bapsang-price-v0.4.0.ait` 전달 (배너 ID가 빌드에 들어갔는지 스크립트가 자동 확인)
   - 전면·보상형은 콘솔에서 아직 못 만듦. 나중에 열리면 2·3번째 값에 넣고 다시 빌드
3. 사장님: 콘솔 앱 출시 → .ait 업로드 → 아래 업데이트 메모 붙여넣기 → 검토 요청
4. 승인되면: 아래 무료 홍보 글 올리기 (숫자는 출시 날 Claude가 최신 시세로 바꿔 드림)
5. 출시 다음 날: 핵심 지표에 '품목 상세 본 유저' 숫자 확인, 콘솔 이벤트 목록에 `shop_clicked` 생겼으면 '전환 지표 추가하기'로 '토스쇼핑 클릭한 유저' 추가
6. 출시 3~7일 뒤: 토스애즈 1주 테스트 (아래)

## 업데이트 메모

사용자에게 보이는 내용:
```
김장철 맞이 업데이트
- 김장 계산기: 배추 포기 수만 고르면 재료비를 오늘 시세로 계산해요
- 김장 재료는 국산 품종 시세로만 보여줘요
- 배추 종류별 보기: 해남·괴산·고랭지·절임배추를 골라 볼 수 있어요
- '평소보다 싸요' 배지: 최근 30일 평균보다 싼 품목을 알려줘요
- 품목마다 토스쇼핑 상품을 바로 볼 수 있어요
```

검토자 메모:
```
- 쇼핑 상품은 토스쇼핑 쉐어링크이며, 화면에 대가성 문구를 표시했습니다. 클릭 보상은 없습니다.
- 시세는 KAMIS(농산물유통정보) 공개 데이터를 매일 자동 수집해 보여줍니다.
- 김장 계산기·배추 보기는 김장철(10/15~12/20)에만 메인에 노출됩니다.
- 화면 하단·품목 상세 하단에 토스 인앱 배너 광고가 있습니다.
```

토스에서 '오늘밥상물가' 검색하면

### 블로그 제목 후보
- 2026 김장 비용 얼마? 배추 20포기 국산 재료 시세로 계산해 봤어요
- 올해 김장, 작년보다 7% 싸요 — 배추 값 한 달 새 33% 내린 이유
- 절임배추 vs 생배추, 해남·괴산·고랭지 가격 비교 (2026년 11월)
